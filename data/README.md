# Data

All files are NumPy `.npz` archives containing only numeric and fixed-width string arrays (no pickled objects; they load with `allow_pickle=False`, which is what every loader in `src/` uses). Files are row-aligned within a model. One row is one sampled chain-of-thought trace. `groups` is the problem id (the unit for all splits), `y` is 1 if the trace's final answer matched the gold answer.

## `scores/scores_<model>.npz` (7 models)

Frozen per-trace scores used by every certificate analysis.

| key | shape | meaning |
|---|---|---|
| `y__<bench>` | (n,) int | correctness label on benchmark `bench` ∈ {gsm8k, arc, strategyqa, csqa, bbhlogic} (bbhlogic missing for some models) |
| `groups__<bench>` | (n,) str | problem id |
| `trainmask__gsm8k__s<seed>` | (n,) bool | GSM8K traces whose problems form the 30% training partition of seed ∈ {0,…,4} |
| `s__<bench>__<signal>__s<seed>` | (n,) float | score of the frozen scorer (fit on that seed's GSM8K training partition) on benchmark `bench`; signal ∈ {confidence, jspace, logitlens, surface, probe, jspace_plus_confidence} |

Scorers: standardization + ℓ2 logistic regression (C = 1 for the readable signals, C = 0.01 for the probe) on all traces of the training problems. `cell_meta.json` lists per-cell trace counts, class balance and feature dimensions.

## `bon/scores_<model>.npz` (Qwen3.5-4B, Qwen3-4B)

Best-of-n experiment: up to 64 sampled traces per GSM8K problem on problems not used anywhere else, scored by one frozen scorer per signal (from `scores/`).

| key | meaning |
|---|---|
| `y`, `groups`, `sample_id`, `uids` | label, problem id, sample index within problem, trace id |
| `s__<signal>` | frozen score; signal ∈ {confidence, jspace, logitlens, randread, surface, probe} |
| `v3heldout_*` | the same scorer's outputs on the held-out GSM8K traces it was frozen on (reference only) |

Analyses keep problems with at least 32 usable traces and draw 32 per problem (`src/goodhart_common.py`).

## `features/features_<model>.npz` (7 models, GSM8K)

Readable feature matrices for the traces in `scores/scores_<model>.npz` (same row order).

| key | columns |
|---|---|
| `X_confidence_only` | 5 statistics of token log-probabilities |
| `X_jspace_only`, `X_logitlens_only`, `X_random_readout_only` | 51 trajectory features of decoded top-20 token distributions (Jacobian lens / logit lens / random transport) |
| `X_surface_only` | 9 geometric features of sentence embeddings of the written steps |
| `X_length_only` | 3 length features |
| `X_jspace_plus_confidence`, `X_all_combined` | concatenations (56 and 119 columns) |
| `cols_*` | column names |

## `features/probe_depths_<model>.npz`

Residual-stream vectors (float16) at three depths × two positions: `early_step`, `early_ans`, `mid_step`, `mid_ans`, `late_step`, `late_ans`, each (n, d_model). The paper's probe uses `[mid_step ‖ mid_ans]`. `uids` aligns rows with `features_<model>.npz`.

## `pipeline_outputs/`

`results_v3_cross.json`, `results_v4_cross.json`: cross-validated AUCs and paired bootstrap differences of every signal per (model, benchmark) cell, produced by `pipeline/jspace_pipeline.py`. Used only for Appendix Table 12 (test AUCs and bootstrap differences).

## Provenance

Generated by `pipeline/` (Modal, single A100s, roughly US$50 in total). Plain-text two-shot prompts with GSM8K training exemplars; temperature 0.8, top-p 0.95, at most 640 new tokens; 2–4 samples per problem (64 for the best-of-n set). Multiple-choice and yes/no answers are parsed with a style-anchored rule because base models often write past their answer.
